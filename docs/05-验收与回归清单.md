## 4. 视觉回归方法（推荐）

用 DOM 断言代替肉眼，把第 2 节的数值写成断言脚本（浏览器控制台或自动化工具均可）：

```js
// 例：顶栏操作区两端一致性
const g = document.querySelector('.admin-topbar-right, .topbar-right');
const [a, b, c] = [...g.children].map(el => el.getBoundingClientRect());
console.assert(Math.abs((b.left - a.right) - 13) < 1, '容器 gap 不符');
const icon = b.querySelector('svg').getBoundingClientRect();
const txt  = b.querySelector('span').getBoundingClientRect();
const exit = c.querySelector('svg').getBoundingClientRect();
console.assert(Math.abs((icon.left - a.right) - 19) < 1, '按钮→登录人 视觉间距不符');
console.assert(Math.abs((exit.left - txt.right) - 19) < 1, '姓名→退出 视觉间距不符');

// 例：数值层级
const v = document.querySelector('.stats-summary .sd-swatch__val');
const s = getComputedStyle(v);
console.assert(s.fontSize === '31px' && s.fontWeight === '600' && s.fontVariantNumeric === 'tabular-nums');
```

**注意两个测试环境的坑**（原型开发期已踩）：
1. 无头浏览器默认 `prefers-reduced-motion: reduce` → **图表出生动效会被自动关闭**，不要误判为"动画坏了"。
2. 截图类工具往往会等画面稳定 → **抓不到动画中间帧**；要验证动效请用 `canvas.toDataURL()` 逐帧采样。

## 5. 可接受的差异

以下变化**不算回归**，无需处理：

- 切换按钮左右边界两端不同（标签字数不同导致，属正常）
- 图表柱数/数值随演示数据变化
- 大屏（≥1920）下所有字号与间距按 ×1.10 放大
- 演示数据（`isDemo: true`）的任务出现在任务记录与统计里
- Element Plus 个别组件（下拉、日期面板）的选中态色值与设计系统**有细微偏差**（属已知技术债，见交接说明第 6 节第 2 条）
