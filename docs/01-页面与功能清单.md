# 01 · 页面与功能清单

> 路由是 **hash 模式**（`createWebHashHistory`），地址形如 `/#/admin/stats`。
> 单文件页面只有 6 个：`Login / SelectProcess / Work / Complete / Projector / Admin`，
> **管理端所有模块共用 `Admin.vue`**，由 `route.path` 推导 `section` 再分支渲染（见 `Admin.vue` 顶部的 `section` 计算属性）。

---

## 1. 端口与角色

| 端口 | 进入方式 | 顶栏 |
|---|---|---|
| 操作员端 | 以 `role === '操作员'` 的人员登录 | 中文产品名 + DISP-MES｜切换至管理端按钮 · 登录人 · 退出图标 |
| 管理端 | 以 `管理员` / `超级管理员` 登录 | 面包屑｜切换至工位端按钮 · 登录人 · 退出图标 |
| 投影窗口 | 独立路由，可在浏览器新窗口/投屏设备打开 | 无顶栏 |

**权限规则**（`Admin.vue`）：
- `permitted = role === 'admin'` —— 只有管理端角色能看到管理端菜单。
- **「人员管理」仅「超级管理员」可进**，其余管理端角色菜单项置灰（`menuDisabled`）。原型的登录账号 `ADMIN-001 / 王工` 就是超级管理员。

## 3. 工位端功能

### 3.1 登录 `Login.vue`
- 工号 + 密码登录（真实校验，非"选择角色"）。默认填充 `OP-018 / 123456` 方便演示。
- 左侧品牌面板：主标题「光影引导 / 装配作业系统」、副标题「过程可视 · 参数可溯」、修饰字「DISP-EMS」、减振器实物图。
- 页脚左右对称：左「成都骤点科技有限公司 · SyncDot」（白字，在蓝色面板上）+ 右版本号（`package.json` 的 `version`，读自 `import { version } from '../../package.json'`）。
- 含「重置演示数据」入口。

### 3.2 工艺选择 `SelectProcess.vue`
- **扫码识别**：输入产品编码后回车（或点击扫码区）→ 自动带出钢印号 → 按型号匹配工艺文件。
- 产品识别字段布局：产品编码独占一行；产品型号与钢印编号在下一行并排展示，窄屏自动改为纵向排列。
- 产品识别框在等待扫码及识别中展示本地扫描动效：渐变扫描区域与扫描线由底向上循环移动，并在虚线框边界裁切；识别成功后隐藏，重新扫码后恢复。该动效不读取或写入业务数据。
  匹配规则（`matchedProcesses`）：编码与 `model` **全等、或以其为前缀（`model-`）、或包含 `model`**，大小写不敏感。
- 匹配结果以工艺卡列表展示（型号、标题、来源文档、工序数、重要工序数），单条时自动选中。
- 底栏右侧「开始作业」（未识别/未选工艺时禁用）。

### 3.3 作业页 `Work.vue`
- **顶部工序进度条**：横向节点（序号 + 标题），当前节点高亮放大；节点可点击跳转。
- 步骤详情：标题、重要工序标记、关联视频；右侧按上方步骤内容、下方工艺参数显示，参数录入权限不变。
  - 参数 `type:0` 手动输入；`type:1` 单选（选项来自 `options`，第一项为合格参考项）；`type:2` 范围值。
  - 范围值的 `referenceValue` 使用四段逗号格式，例如 `(>30),(=30),(=70),(<70)`；操作端显示边界含义并允许如实录入超限值。
- **投影区**：按当前工序的投影元素渲染（图标 + 变量文本）。
- 开始作业自动打开或复用固定投影窗口 `/op/projector`；在 Chrome/Edge 授予“管理窗口”权限并完成投影屏设置后，窗口会自动铺满已选副屏的可用工作区；不支持或未授权时降级为普通投影窗口。
- 底栏：上一步 / 下一步。
- **跳转工序**：向前跳会为跳过的步骤补写审计记录（区分重要工序与普通工序）；下拉列表中的重要工序以黄色五角星标记。

### 3.4 完成确认 `Complete.vue`
- 汇总所有已完成步骤的参数（`completionItems()`），操作员可修改；全部参数填写完成后才可提交或交接。
- 提交 → `completeTask(items)`：写 `completionForm`、任务置为「已完成」、算 `durationSec`、进 `taskHistory`。
- 提交后表单变只读；**取消不改状态**（任务仍为「进行中」）。

### 3.5 投影窗口 `Projector.vue`
- 全屏投影画布，固定 **1920×1080** 逻辑坐标，等比缩放适配屏幕。
- 元素类型：图标（可 `scale` / `rotation` / `blink`）、文本（字体大小/颜色/变量插值）。
- 三种进入方式：工位投影、步骤投影编辑预览、模板预览（由路由区分）。

## 4. 管理端功能

菜单分三组（`Admin.vue` 的 `menus`）：

### 4.1 工艺与资源
| 模块 | 功能 |
|---|---|
| **工艺文件** `/admin/processes` | 两张数据卡（有效型号 / 重要工序，色卡样式）；工艺列表表格；**导入工艺**（Excel 解析 + 预检）；删除（带引用预检）；点击进详情 |
| **视频资源** `/admin/videos` | 视频列表（名称/分类/时长/批次，分类筛选和搜索后分页）、上传（含批量；重名时可替换或取消）、是否允许作业会话预览、删除 |
| **投影素材** `/admin/icons` | 图标素材卡片（白卡面 + 品牌渐变图区 + 白色图标）、上传 PNG、查看（弹窗）、删除 |
| **投影模板** `/admin/projector/templates` | 模板卡片（眉标：默认/自定义 → 标题 → 操作：编辑模板 / 重命名 / 删除）；新建模板；**默认模板不可删** |

**工艺详情** `/admin/processes/:id`：左侧工序列表（重要工序标题右侧显示黄色五角星标记），右侧步骤标题、可选步骤内容、工位/视频/参数编辑及该工序投影配置（可套用模板或逐个编辑）。步骤内容可从 Excel “步骤内容”列导入；旧模板缺列时留空。带「步骤投影预览」与「实况窗口」。

**模板编辑器** `/admin/projector/templates/:id`：拖拽图标/文本元素、改坐标/大小/旋转/层级/颜色/字体大小、设置模板变量（`{{stepTitle}}` 等）。

### 4.2 生产与记录
| 模块 | 功能 |
|---|---|
| **任务记录** `/admin/tasks` | 在制与已完成任务列表（产品编码、型号、钢印号、状态、各工位/操作员/完成步骤）；已完成记录保存在 `taskHistory` 供后续查询。 |
| **步骤审计** `/admin/tasks/:id/audit` | 工位步骤操作明细与跳步原因；钢印号修改额外展示操作员、工位及修改前后编号，**跳步只在审计日志留痕** |
| **生产统计** `/admin/stats` | 近 7 日 / 近 30 日 / 自定义日期筛选；完成件数、在修积压、一次合格率、总平均耗时、平均最长耗时型号、平均最佳耗时型号六张经营指标卡；11 工位实时状态（悬停查看在制型号与钢印号）；参数偏离排行、按型号的工序耗时比重环形图及近 12 个月直线产能趋势；支持页面专注全屏模式（隐藏系统导航）。 |

### 4.3 系统配置
| 模块 | 功能 |
|---|---|
| **人员管理** `/admin/users` | 人员列表（工号/姓名/角色/部门/手机号/状态）；新增、编辑、重置密码、删除；**仅超级管理员可见** |
| **工位管理** `/admin/workstations` | 管理员可新增工位、编辑工位名称及“手动输入 / 自动获取最新绑定”模式；工位 1 为默认归属不可删除，删除其它工位会将当前工艺步骤迁移到工位 1。 |

> 管理端右上角操作区：切换至工位端 · 登录人（点开「个人信息 + 修改密码」弹窗，两端复用 `UserProfileDialog.vue`）· 退出。

## 5. 关键业务规则（改代码前务必理解）

1. **工艺快照冻结**：任务开始时把 `processSteps` 与各工序投影配置**深拷贝进任务**（`processSnapshot` / `projection`）。此后管理端编辑工艺或模板**不得影响在制任务**。
2. **跳步留痕**：`actionCode` —— `0` 完成、`1` 普通工序跳过、`2` 重要工序跳过。只有 `0` 计入完成进度；`>0` 进审计日志。
3. **删除前引用预检**：所有删除都先展示引用数量（如"该工艺被 N 个任务引用"），确认后才逻辑删除；删的是"当前工艺"时会自动回退到另一份可用工艺。
4. **逻辑删除**：`state.deleted` 登记被删 id，列表读取时过滤，不做物理删除。
5. **默认模板保护**：`isDefault` 的模板（`T-001`）只能编辑、不能删除；所有导入的工序自动绑定它。
6. **导入预检**：Excel 解析后逐行校验，参数类型缺失（`sourceTypeMissing`）列为错误（随包演示文件有 22 处），提供"演示修正"开关便于走通流程；新范围值必须是四段逗号格式，旧两行数值格式继续兼容。填写视频名称时会匹配视频资源，兼容常见视频扩展名差异；未找到或匹配到多个视频会阻止导入并标注来源行。
7. **投影变量绑定**：文本元素的 `{{变量}}` 在渲染时替换（工序号/标题/进度/型号/钢印号/参数名与参数值），未录入时回落到参考值。

8. **工位分段交接与独立任务（v2）**：操作员登录选择并记忆工位；产品编码仅用于扫码读取或替换当前扫码载体，**每个钢印编号对应一条独立在制任务，钢印号才是任务、步骤进度和工位交接的唯一标识**。浏览器 mock 以 `steelNo → taskId` 保存多条在制任务；手动工位可用新产品编码加既有在制钢印号恢复对应任务，系统记录产品编码替换审计；自动工位仍可由产品编码带出型号、钢印号和任务。步骤按 `stationId` 分配，后续工位仅在前置工位汇总确认后可录入；每站末步确认本站汇总，最终站额外确认全产品总汇总。
9. **工位内跳步与回改（v2）**：当前工位可跳到本站任一步骤；向后跳时，中间未完成步骤按重要性写入跳过审计。本站已完成步骤在本站汇总确认前仍可重新打开并修改参数，保存后复写该步骤的操作人、时间和参数值。查看其它工位步骤不会取得录入权限，点“下一步”会回到本工位第一条待完成步骤。
10. **测试数据重置（原型专用）**：登录页“重置测试数据”经二次确认后清除本浏览器的 localStorage 状态并恢复初始演示数据。正式后端开发/上线前必须移除该入口与 `reset()` mock 行为。
11. **实时投影联动（v2）**：开始作业时自动打开或复用固定命名的投影窗口；投影窗口从同一份任务快照按 `currentStepIndex` 取当前步骤，并轮询浏览器缓存。工位端保存、跳转或回改步骤后，投影应切换到该步骤的冻结投影配置，不能按“步骤号 = 下标 + 1”推断。
12. **完成归档、解绑与下一件（v2）**：最终确认时将完整任务快照归档至 `taskHistory`，其中每条完成日志保留 `stationId`、`operatorName`、步骤、参数与时间；随后仅删除**该钢印号**的在制任务绑定及其当前产品编码映射，其它钢印号的在制任务不受影响。完成页“录入下一件”会清除当前已完成任务的作业上下文；手动工位扫描新的产品编码后可重新选择型号、填写新的钢印号并创建新绑定，自动工位仍只能读取在制绑定。
13. **最终确认锁定（v2）**：末工位确认本站汇总进入“最终参数汇总”后，不再提供“返回作业”入口；该页面只允许检查全流程参数并确认完成。非最终的本站汇总仍可返回作业修改本站参数。
