# 04 · 设计系统使用规范（**改 UI 前必读**）

> 本原型的视觉是**逐像素评审过**的。接手后的默认要求是：**只接数据，不动 UI**。
> 若确实需要新增界面，请按本文档使用设计系统，不要自创样式。

---

## 1. 三层样式结构与注入顺序（不要改顺序）

`src/main.js` 里按此顺序注入：

```js
import './design/tokens.css'      // ① 设计系统 · 变量层（颜色/字号/间距/圆角/动效时长）
import './design/components.css'  // ② 设计系统 · 组件层（.sd-* 组件类）
import './style.css'              // ③ 项目层（页面级样式 + 对 ①② 的少量覆盖）
```

- ③ 在最后，所以**项目层可以覆盖设计系统** —— 现有代码大量依赖这一点（例如把 `.sd-swatch__val` 的文字颜色改成继承卡面）。
- **不要**把 `style.css` 提到前面，会造成大面积样式失效。
- 页面级样式**绝大部分写在 `style.css`**，而不是 `design/`。改页面间距/布局请去 `style.css`。

## 2. 版本情况 ⚠️ 最容易出错的地方

| 位置 | 版本 | 用途 |
|---|---|---|
| `src/design/` | **v1.11 的局部同步副本** | 运行时实际生效的样式 |
| `design-system/`（本包内） | **v1.17 权威源** | 后续新页面/新组件的规范参考，**不参与运行** |

- 项目副本已经在 2026-09-20 按需**局部同步**到 v1.17：数值层级（`.sd-swatch__val` / `.sd-stat__value` / `.sd-card__value`）+ 新增 `--duration-slow` / `--duration-draw`。
- **禁止**把 `design-system/tokens.css`、`components.css` 整体覆盖到 `src/design/`：v1.11 → v1.17 有 260+ 行差异，会直接造成大面积视觉回归。整合同步必须**单独立项 + 全量回归**。
- 需要新组件时：从 `design-system/components.css` 里**摘取单个组件规则**接入，并在提交说明里写清楚摘了哪一段、对应 v1.17 的哪一节。

## 3. Token 速查（**禁止硬编码**）

### 字号 —— 只有 9 档（大屏会自动放大）
`--fs-10: 10` · `--fs-11: 11` · `--fs-12: 12` · `--fs-13: 13` · `--fs-14: 14` · `--fs-16: 16` · `--fs-24: 24` · `--fs-28: 28` · `--fs-48: 48`（px）

大屏断点：**≥1920 全局 ×1.10**，**≥2560 ×1.22**（由 tokens 重定义实现，写死 px 会在大屏下失真）。

### 控件高度 —— 只有 3 档
`--control-h: 32px`（默认）· `--control-h-sm: 24px` · `--control-h-lg: 40px`（底栏主操作）

### 间距
`--space-1..8` = `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`（px，同样随大屏放大）

### 圆角
`--radius-sm: 2` · `--radius-md: 6`（按钮/输入框）· `--radius-lg: 8`（卡片）· `--radius-xl: 12` · `--radius-pill: 999`

### 颜色
| 用途 | Token | 值 |
|---|---|---|
| 界面主色（按钮/链接/选中） | `--sd-blue-6` | `#0077FA` |
| 主色加深（hover/active） | `--sd-blue-7` | `#005FD4` |
| 品牌识别色 · 蓝（Logo/品牌区） | `--brand-blue` | `#509BEB` |
| 品牌识别色 · 青（Logo/品牌区） | `--brand-cyan` | `#50D2EB` |
| 页面底色 | `--page-bg` | `#FFFFFF` |
| 次级面（**仅**侧栏 / 卡内嵌次级块） | `--page-surface` | `#F7F9FC` |
| 更浅面 | `--page-surface-muted` | `#EFF3F8` |

> **品牌识别色 ≠ 界面主色**：品牌蓝青只用于 Logo、品牌物料、双色斜线；界面按钮/链接一律用 `--sd-blue-6`。
> **禁止给布局总容器铺 `--page-surface`**（会让整页发灰）。

### 动效
`--duration: 200ms` · `--duration-fast: 120ms` · `--duration-slow: 600ms`（生长类）· `--duration-draw: 900ms`（描线/淡入类）· `--ease: cubic-bezier(.4,0,.2,1)`

## 4. 数字排版（v1.17「数值层级」）

看板/数据卡里**数值是最重要的一行，层级高于同卡标题**：

| 层级 | 类 | 字号 / 行高 / 字重 | 用途 |
|---|---|---|---|
| **L1 主数值** | `.sd-swatch__val` · `.sd-card__value` · `.sd-feature-card__value` | **28 / 1.43 / 600** | 色卡、数据卡、功能卡主数值 |
| **L2 统计值** | `.sd-stat__value` | **24 / 1.3 / 600** | 统计卡与指标组 |
| **L3 表格与图表数字** | `.sd-table .num` · `.sd-chart__barval` | 13 / 11 · 400 | 表格数字列、图表轴与数值标签 |

**硬规则**
- 三层**全部**走 `--font-num`（= `--font-sans`）+ `font-variant-numeric: tabular-nums`。
- **`--font-mono` 只授权给**：行内代码、代码块、表格数字列、图表数值、色值 HEX。**禁止**用等宽字体渲染大号装饰数字（Windows 下会回退 Consolas，字形不符）。
- **数值不补前导 0**：显示 `1` 而不是 `01`。
- 数值串建议 ≤ 8 字符；单位/口径说明放说明行，不要塞进数值本身。
- 两个数值类不要叠在同一元素上。

## 5. 组件用法要点

### 标题装饰（品牌语言，别漏）
- **一级标题**（页头 h1）：右侧蓝色切割元素 → 用 `.sd-page-head h1`，或等价类 `.sd-title-cut`
- **二级标题 / 卡片标题**：左侧**双色斜线**（品牌蓝 + 青）→ `.sd-card__title` 自带；纯文字标题加 `.sd-card__title--plain`
- 装饰元素垂直居中靠 `transform: translateY(var(--ink-nudge))`（中文墨迹微调 `0.05em`）。**新增装饰元素必须带上这一句**，否则会偏高 1~2px。

### 卡片与色卡
- 卡片：`.sd-card`（自带 1px 边框 + `--shadow-1`）· 卡片标题 `.sd-card__title`（`--fs-16` / 500）
- **品牌色卡 `.sd-swatch` 档位顺序（硬规则）**：
  **2 张 → 必须用品牌双色 `sd-swatch--blue` + `sd-swatch--cyan`**；
  **3 张及以上 → 依次补浅色档 `--blue-1` / `--cyan-1`**。
  （浅色档只在第 3 张之后才允许出现。）

### 图标
- 界面图标用 Element Plus 图标（已在 `main.js` 全局注册，模板里直接 `<UserFilled />` 即可）。
- **深色底上的图标白化**：`filter: brightness(0) invert(1)`。
  ⚠️ **深底必须挂在 `<img>` 之外的独立容器上** —— `filter` 会连同元素自身的 `background` 一起反白。
- ⚠️ **白图标与深底是互锁的**：把底换成浅色就**必须**同时去掉反白滤镜，否则图标直接隐形（投影素材卡片踩过这个坑）。

### 图表（ECharts）
- **一律走 token 桥接**：用 `getComputedStyle(document.documentElement)` 读 `--chart-*`，**禁止写死 hex**（`ProductionInsightsCharts.vue` 的 `theme()` 是范本）。
- 习惯约定：趋势图 `showSymbol:false` + `axisPointer.z=1` + halo/core 双 series；横向柱图 yAxis 带 **`inverse: true`**（配合"数据已按值降序"才能让第一名在最上面）。
- **出生动效**（v1.17「图表出生动效」）：规范原身是纯 CSS（`.sd-chart-anim` + `.sd-anim-line/-area/-bar-x/-bar-y/-arc/-needle/-fade`，组容器 `.sd-anim-seq` 每级 +40ms，`.sd-anim-reveal` 入视口播放）。本项目图表是 ECharts canvas，**已在 `ProductionInsightsCharts.vue` 里映射时长与缓动**：
  折线/面积 = `--duration-draw`(900ms)、柱 = `--duration-slow`(600ms)、同组柱 `animationDelay = idx*40`、`animationEasing:'cubicOut'`（近似 `--ease`）、IntersectionObserver 实现入视口播放、`prefers-reduced-motion` 时整体关闭。
  **改图表动效时请同步这几项，别只改 duration。**

### 表格 / 弹窗
- 表格统一 `.mes-table`（EP el-table 封装）。
- 三种按钮语义不要混用：`.table-action`（表格内弱操作）、`.ghost-button`（次按钮）、`.admin-primary`（主按钮）。
- 弹窗底栏：`display:flex; justify-content:flex-end; gap:12px`；表单原生控件写法必须是 `label > input:not([type=file])`（**用后代选择器会误中 el-select 内部 input，出现双边框**）。

## 6. 布局约定

- `--content-max: 100%`、`--sidebar-w: 232px`；页头/操作行与内容区间距统一 `--space-5`（24px）。
- 管理端顶栏 `.admin-topbar` 需 `justify-content: space-between`；**两端顶栏右侧统一为操作区**：切换端按钮 → 登录人（蓝图标 + 姓名，无框无底色）→ 退出（纯图标）。
- 登录人点击打开共享组件 `src/components/UserProfileDialog.vue`（个人信息 + 修改密码），**两端复用同一个，不要各写一份**。
- 栅格：`.sd-grid-2/3/4` 或页面自定义 grid；卡片组**始终填满宽度**，≤640px 收单列。

## 7. 常见坑（都是本项目已踩过的）

| 坑 | 现象 | 规避 |
|---|---|---|
| `span:last-child` 之类**位置型选择器** | 加/换元素后样式**静默失效**（不报错） | 用显式类名定位 |
| `.plain-icon` 这类 32px 命中区里图标只有 16px | 视觉间距比 CSS `gap` 宽 8px，「看着不等距」 | 需要光学配平时用负外边距补偿 |
| EP 弹窗关闭后 DOM 仍驻留 | 脚本按选择器取到旧元素 | 按可见性筛选（`offsetParent !== null`） |
| `filter` 与 `background` 同挂一个元素 | 深底被一起反白 | 深底挪到外层容器 |
| 绝对定位的 SVG | 不显式给 `height` / `aspect-ratio` 会塌陷 | 显式尺寸 |
| hash 路由下重复 `open` 同一 URL | 页面不重载 | 需 `location.reload()` |
