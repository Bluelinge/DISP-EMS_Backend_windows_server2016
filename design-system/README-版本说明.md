# SyncDot Design 设计系统 — 权威源 v1.17

本目录是**设计系统的权威参考源**（不是运行时依赖）。原型运行时实际加载的是 `../src/design/` 里的副本。

| 文件 | 内容 |
|---|---|
| `tokens.css` | 全部设计变量：颜色、字号阶梯、间距、圆角、阴影、动效时长、大屏断点 |
| `components.css` | `.sd-*` 组件类：按钮 / 表单 / 表格 / 标签 / 提示 / 进度 / 骨架布局 / 卡片 / 动效工具类 / 品牌色卡 / 功能卡 / 商品卡 / 图表与环形图 / 仪表盘 / 横向柱图 / 图表出生动效 / 标题装饰 |
| `USAGE.md` | **规范正文（最全）**：每个章节含结构示例、参数、注意事项。查规范优先看它 |
| `SKILL.md` | 规范的速查映射表（组件 → 类名 → 要点） |

版本：**v1.17**

## ⚠️ 首要警告：**不要用它整体覆盖 `src/design/`**

原型里的 `src/design/` 是 **v1.11 的局部同步副本**。v1.11 → v1.17 在 `components.css` 上有 **260+ 行差异**，直接覆盖会造成大面积视觉回归。
整合同步必须**单独立项 + 全量视觉回归**。

### 项目副本已同步到 v1.17 的部分（2026-09-20）

| 变更 | 内容 |
|---|---|
| **数值层级** | `.sd-swatch__val` → `28 / 1.43 / 600`（原 14px/400）；`.sd-stat__value` 行高 `1.1 → 1.3`；`.sd-card__value` 字重 `500 → 600`、行高 `1.2 → 1.43` |
| **动效 token** | 新增 `--duration-slow: 600ms`（生长类）、`--duration-draw: 900ms`（描线 / 扫弧 / 淡入类） |

### 项目内**未同步**的已知差异（改动相关代码时请留意）

- 项目自定义了 `--title-mark-nudge`（v1.12 起官方更名为 `--ink-nudge`，项目里通过 `style.css` 桥接同值）。
- 项目里的 `.sd-alert` 是简化版；官方 v1.17 另有一套 `.sd-message` 等反馈组件。
- v1.17 的**图表出生动效**是一整套纯 CSS 类（`.sd-chart-anim` + `.sd-anim-*` + `.sd-anim-seq` + `.sd-anim-reveal`）。本项目图表用 ECharts canvas，无法直接套用这些类，**已在 `src/components/ProductionCharts.vue` 里把规范的时长 / 错峰 / 缓动 / 视口触发逐项映射为 ECharts 配置**。要改图表动效请看该文件顶部注释。

## 怎么用这份权威源

1. **先查 `USAGE.md`** 找到对应章节，复制 `components.css` 里的**那一小段规则**（不要整文件）到项目。
2. 在提交说明里注明摘取来源与版本，便于日后同步。
3. 颜色 / 尺寸**一律用 token 变量**，不要复制 v1.17 里的字面值（项目副本的变量阶梯与 v1.17 可能不同）。
4. 新增页面前，先看 `USAGE.md` 的「布局骨架 / 栅格 / 卡片 / 字体规则 / 数值层级」几章——绝大多数页面由这几章组合即可，不需要自创样式。

## 设计系统的核心约束（速记）

- **字体**：`--font-display`（MiSans，仅标题/品牌字）· `--font-sans`（正文/界面/一切装饰文字）· `--font-mono`（**仅**代码、表格数字列、图表数值、HEX 色值）
- **字号**：只有 9 档（`10/11/12/13/14/16/24/28/48`）
- **控件高**：只有 3 档（`32 / 24 / 40`）
- **数值层级**：L1 `28/1.43/600` · L2 `24/1.3/600` · L3 `13/11/400`，全部 `tabular-nums`；**不补前导 0**
- **色卡档位**：2 张用品牌双色（`--blue` + `--cyan`）；3 张及以上才依次补浅色档（`--blue-1` / `--cyan-1`）
- **标题装饰**：一级标题右侧蓝色切割元素；二级/卡片标题左侧双色斜线（蓝 + 青）
- **动效**：`--duration 200ms` / `--duration-fast 120ms` / `--duration-slow 600ms` / `--duration-draw 900ms`；`prefers-reduced-motion` 下**必须**自动关闭
